# 🎧 Radio-Online

> **Крутое онлайн-радио прямо в браузере**: выбирай страну, находи волну по жанру и запускай эфир в один клик.

## ✨ Что умеет

- 🌍 Выбор страны из большого каталога.
- 🇷🇺 Улучшенная поддержка **русских волн** и режим русскоязычных станций со всего мира.
- 🔎 Поиск по названию станции, тегам и языку.
- 🎚️ Фильтры по жанру, языку, битрейту, проверенным потокам и избранному.
- ↕️ Сортировка по популярности, качеству, названию, языку и стабильности.
- ⭐ Избранные станции с сохранением в браузере, импортом и экспортом JSON.
- 🧭 Режимы по настроению: работа, дорога, новости, ретро, русский эфир и случайная страна.
- 📻 Очередь эфира, случайный запуск, горячие клавиши и запоминание громкости.
- 🕘 История последних прослушанных волн.
- 💤 Сонный таймер на 15/30/60/90 минут.
- ▶️ Быстрый запуск потока, автопереход к следующей станции при сбое и защита от зацикливания на битых потоках.
- 🎙️ Реплики эфирного ведущего в ночном, дневном, новостном, ретро и рок-форматах.
- 🎨 Темы оформления: Night Neon, Ocean, Retro FM и Light.
- 📱 PWA-режим: приложение можно установить, а базовая оболочка кэшируется service worker'ом.

---

## 🚀 Как запустить

1. Склонируй репозиторий.
2. Открой файл `index.html` в браузере.
3. Выбери страну и станцию — и наслаждайся эфиром.

> Для проверки PWA-возможностей лучше запустить проект через локальный HTTP-сервер, например `python3 -m http.server 8000`.

---

## 🧠 Технически

- Источник станций: Radio Browser API с зеркалами `de1`, `nl1` и `at1`.
- Клиент полностью статический: без сборки и без серверной части.
- Состояние избранного, истории, темы, громкости и кэша каталога хранится в `localStorage`.
- Offline shell реализован через `manifest.json` и `service-worker.js`.
